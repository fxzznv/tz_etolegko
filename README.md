# etolegko — замер скорости интернета

Консольный скрипт на Python, который принимает адрес (например, ссылку на
тяжёлую картинку), делает к нему 10 запросов последовательно, дожидаясь
полного ответа на каждый, и считает скорость скачивания.

## Требования

- Python 3.8+ (стандартная библиотека, зависимостей нет)

## Запуск

```bash
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://example.com/large-image.jpg
```

## Что делает скрипт

1. Выполняет 10 последовательных HTTP(S)-запросов к указанному адресу.
2. Для каждого запроса читает ответ целиком и замеряет время.
3. Печатает таблицу: размер ответа, время и скорость по каждому запросу.
4. В конце выводит сводку:
   - среднее время запроса (секунды);
   - общий объём скачанных данных (автоматически в Б/КБ/МБ/ГБ, 1024-базные единицы);
   - **среднюю скорость скачивания в МБ/с** (десятичные: 1 МБ = 1 000 000 байт,
     считается как суммарный объём / суммарное время всех запросов).

## Примечания

- Таймаут на один запрос — 60 секунд.
- Запросы идут строго последовательно, кэширование не используется.
- Для честного замера используйте файл, который не помещается в кэш CDN/браузера
  или добавляйте к URL меняющийся query-параметр.
